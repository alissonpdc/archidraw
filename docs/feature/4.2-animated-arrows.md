# Feature 4.2: Animated Arrows (Setas Animadas)

## Objetivo
Visualizar fluxo/movimento entre componentes com animação contínua nas setas.

## Efeito Visual

### Tipo de Animação
- Linhas em movimento ao longo da seta (tipo "loading bar" ou "marching ants")
- Segmentos animados que se movem continuamente na direção da seta

### Aparência
- Pequenos traços ou pontos que "caminham" pela seta
- Cor diferente do stroke normal (ex: cor mais clara ou brilhante)
- Velocidade é constante

## Ativação/Desativação

### Toggle Global
- Um único toggle que ativa/desativa animação para **todas as setas do diagrama**
- Localizado no painel de estilos (Feature 11.2) ou toolbar
- Não é por seta individual

### UI para Toggle
- Checkbox ou button "Animate Arrows"
- Quando ativado: todas as setas ganham animação
- Quando desativado: todas as setas param (voltam a estática)

## Controles de Velocidade

### 3 Presets
1. **Lenta** - movimento lento e deliberado (ex: 2s por loop)
2. **Normal** - velocidade padrão (ex: 1s por loop)
3. **Rápida** - movimento rápido (ex: 0.5s por loop)

### Interface
- Dropdown ou radio buttons no painel de estilos
- Seleção aplica a **todas as setas** do diagrama
- Mudança é imediata (setas reajustam velocidade)

### Custom Speed (Could Have)
- Campo de input para especificar duração exata em ms
- Aplica globalmente

## Persistência

### Salvar/Carregar
- Estado da animação (on/off) é salvo no projeto
- Velocidade selecionada é salva

### Export
- **SVG:** animação pode ser exportada como CSS animation ou descartada (flattened)
- **PNG:** snapshot da animação em um frame específico
- **(.archidraw):** configuração é preservada

## Performance

### Render Efficiency
- Animação usa requestAnimationFrame ou CSS animations
- Não causa lag em canvases com muitos objetos
- Pode ser desativada em baixo desempenho (Could Have)

## Não está incluído nesta feature

- Por-arrow animation controls (Feature futura)
- Custom animation patterns (Feature futura)
- Animation triggers/events (Feature futura)
- Direction reverse (Feature futura)

## Edge Cases

- **Muito muitas setas:** animação continua funcionando smoothly
- **Zoom ativo:** animação acompanha escala visual (sente-se correta)
- **Pan/movimento:** animação continua mesmo se seta está fora de viewport
- **Seta deletada:** animação para (obvio)
