# Feature 4.1: Magnetic Snapping para Setas (Magnetic Snapping for Arrows)

## Objetivo
Facilitar a conexão visual entre componentes permitindo que setas "grudem" automaticamente em pontos de conexão de formas.

## Pontos de Conexão

### Localização
4 pontos de conexão por forma (não diagonal):
- **Topo:** centro superior (top-center)
- **Base:** centro inferior (bottom-center)  
- **Esquerda:** centro esquerdo (left-center)
- **Direita:** centro direito (right-center)

### Formas que Suportam
- Retângulo, círculo, losango, triângulo
- Texto (se tratado como forma)
- **Linhas/setas SEM pontos de conexão** (elas têm endpoints que se conectam)

## Mecanismo de Snapping

### Raio de Detecção
- Quando o endpoint de uma seta fica a **~10-15px** de um ponto de conexão, snapping é ativado
- Raio é ajustável (Could Have)

### Visual Feedback Antes de Snap
- Quando o endpoint está próximo (mas sem snap ainda), nenhum feedback visual
- Quando entra na zona de snap, ponto de conexão é **highlighted** (ex: círculo verde)

### O Momento do Snap
- Quando o endpoint entra na zona e usuário solta o mouse:
  - Endpoint **"gruda"** no ponto de conexão
  - Seta é conectada permanentemente (enquanto ambos os pontos existem)

### After Snap
- Endpoint permanece "magnetizado" ao ponto de conexão
- Se o objeto conectado é movido, a seta acompanha (conexão é "viva")
- Se o objeto é deletado, a conexão quebra (seta fica solta)

## Comportamento de Movimento Pós-Snap

### Se o Objeto Conectado se Move
- Seta acompanha o movimento do endpoint
- Endpoint permanece no ponto de conexão do objeto

### Se a Seta se Move
- O usuário pode mover a seta (Feature 1.3)
- Se nenhum punto de conexão próximo, seta mantém seu estado atual

### Se o Usuário Tenta Desconectar
- Arrastar o endpoint para longe do ponto de conexão (> raio) desconecta
- Seta volta a ser "livre"

## Múltiplas Conexões

### Endpoints Independentes
- Uma seta pode ter:
  - Ambos endpoints conectados
  - Um endpoint conectado, outro livre
  - Ambos endpoints livres

### Muitas Setas no Mesmo Ponto
- Múltiplas setas podem conectar no mesmo ponto de um objeto
- Nenhuma limite de conexões

## Desabilitar Snapping

### Ignorar Snapping
- Segure **Alt** (ou Ctrl) durante o drag para ignorar snapping
- Endpoint não vai agrupar mesmo dentro da zona
- Útil para desenhar setas próximas sem conectar

## Não está incluído nesta feature

- Custom connection points (Feature futura)
- Connection path customization (Feature futura)
- Label de conexão (Feature futura)

## Edge Cases

- **Objeto muito pequeno:** Pontos de conexão ainda existem, snapping funciona
- **Seta dentro de outro objeto:** Snapping ainda funciona
- **Deleteando objeto conectado:** Seta fica solta (endpoint não conectado)
- **Renomeando/redimensionando objeto:** Conexão é mantida
