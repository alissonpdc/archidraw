# Feature 1.4: Redimensionamento de Objetos (Object Resizing)

## Objetivo
Permitir que o usuário ajuste o tamanho e as proporções de objetos selecionados via handles de redimensionamento.

## Handles de Redimensionamento

### Posição e Quantidade
8 handles distribuídos ao redor do objeto:
- **4 corners:** superior-esquerdo, superior-direito, inferior-esquerdo, inferior-direito
- **4 midpoints:** topo-centro, base-centro, esquerda-centro, direita-centro

### Visual
- Pequenos quadrados (6x8px ou similar)
- Mesma cor do contorno de seleção (ex: azul)
- Aparecem apenas quando objeto está selecionado

### Cursor
Muda quando hovering sobre um handle:
- **Corner handles:** cursor diagonal (↖, ↗, ↙, ↘)
- **Midpoint handles:** cursor horizontal ou vertical (↔, ↕)

## Fluxo de Redimensionamento

### Redimensionamento Simples
1. Selecione um objeto
2. Clique e arraste um handle para nova posição
3. Objeto é redimensionado em tempo real
4. Solte para finalizar

### Redimensionamento Mantendo Aspecto
1. Segure **Shift** enquanto clica e arrasta um handle
2. Proporção (aspect ratio) é mantida
3. Objeto cresce/encolhe proporcionalmente

## Comportamento de Redimensionamento

### Redimensionamento por Corner
- Drag em um corner ajusta tanto largura quanto altura
- O handle drag define a nova posição do corner
- O canto oposto permanece fixo

### Redimensionamento por Midpoint
- **Midpoint horizontal:** ajusta largura apenas
- **Midpoint vertical:** ajusta altura apenas

### Dimensão Mínima
- Objetos têm tamanho mínimo (ex: 10x10px)
- Não podem ser redimensionados abaixo desse tamanho
- Se usuário tenta, redimensionamento para no mínimo

### Inversão de Tamanho
- Se usuário arrasta handle além do canto oposto, o objeto **inverte** (espelha)
- Exemplo: arrastando corner superior-esquerdo para baixo-direita inverte vertical e horizontal
- Mantém a forma mas com orientação invertida

## Visual Feedback

### Durante Redimensionamento
- Objeto é redimensionado em tempo real (não com delay)
- Mostra dimensões atual (ex: "480 × 320") em tooltip ou status bar
- Contorno do objeto permanece destacado
- Handles permanecem visíveis e acompanham redimensionamento

### Redimensionamento com Shift
- Cursor muda ou há feedback visual (ex: indicador "constrain" perto do cursor)
- Aspecto ratio é mantido visualmente

## Restrições e Limites

### Sem Restrição de Espaço
- Objeto pode ser redimensionado para ocupar todo o canvas virtual
- Tamanho máximo é apenas limite de coordenadas (32-bit)

### Aspecto Ratio
- Shift+drag mantém aspecto ratio da forma original
- Aplicável a todos os tipos de formas

## Comportamento por Tipo de Forma

### Formas Simétricas (Retângulo, Círculo, Losango)
- Redimensionamento é direto
- Com Shift, mantém proporção original

### Triângulo
- Redimensionamento muda altura e base
- Com Shift, mantém proporção original

### Linha e Seta
- Handles aparecem nos endpoints (início e fim)
- Drag em endpoint move aquele ponto da linha
- Comprimento e ângulo são ajustados dinamicamente

### Texto
- Redimensionamento muda o "caixa de texto" (bounding box)
- Texto dentro reflui para nova altura/largura
- Fonte não escala (apenas o espaço disponível)

## Múltiplos Objetos Selecionados

**Redimensionamento individual não é possível com múltiplos selecionados.**
- Quando múltiplos objetos estão selecionados, **não aparecem handles individuais**
- Usuário deve primeiro:
  - Clicar em um para seleção simples, OU
  - Usar Feature 5.2 (Distribuição) para ajustar tamanho coletivamente

## Não está incluído nesta feature

- Free-form distortion (deformação livre) → Feature futura
- Rotation (rotação) → Feature futura
- Aspect ratio lock global → Feature 2.1 poderia oferecer isso
- Resize by specific dimensions input → Feature 11.2 (painel de propriedades)

## Edge Cases

- **Redimensionar abaixo do mínimo:** Para no tamanho mínimo (10x10px)
- **Redimensionar com zoom ativo:** Movimento é relativo ao zoom (sente-se natural)
- **Dragging muito rápido:** Acompanha velocidade, sem lag
- **Arrastar para coordenadas negativas:** Permitido (canvas infinito)

## Curva de Aprendizado

| Ação | Resultado |
|------|-----------|
| Drag em corner | Redimensiona 2 dimensões |
| Drag em midpoint | Redimensiona 1 dimensão |
| Shift+drag | Mantém aspecto |
| Duplo-clique em handle | Could Have: resetar tamanho original |
