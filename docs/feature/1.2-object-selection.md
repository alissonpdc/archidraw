# Feature 1.2: Seleção de Objetos (Object Selection)

## Objetivo
Permitir que o usuário selecione um ou múltiplos objetos para edição posterior. Suporta:
1. Seleção simples (clique em um objeto)
2. Multi-seleção via Shift+clique
3. Seleção em caixa (drag-box selection)

## Modos de Seleção

### Seleção Simples: Clique
- Clique em um objeto desseleciona todos os outros e seleciona apenas aquele
- Clique no canvas vazio desseleciona tudo

### Multi-Seleção: Shift+Clique
- Shift+clique em um objeto **adiciona** à seleção atual
- Shift+clique novamente no mesmo objeto **remove** da seleção (toggle)
- Se nenhum objeto está selecionado, Shift+clique seleciona apenas aquele objeto

### Seleção em Caixa: Drag-Box
- Clique e arraste na área vazia do canvas (não em um objeto)
- Um retângulo de seleção aparece durante o drag
- Ao soltar, todos os objetos **completamente dentro** da caixa são selecionados
- Objetos parcialmente dentro são **ignorados** (não selecionados)
- A seleção em caixa **substitui** a seleção anterior (não adiciona)

## Comportamento de Seleção

### O que é Selecionável
- Qualquer forma (retângulo, círculo, losango, triângulo, linha, seta, texto)
- Grupos (são tratados como uma unidade)

### Visual Feedback (Objeto Selecionado)
- Contorno/highlight ao redor do objeto (cor específica, ex: azul ou verde)
- 8 handles de redimensionamento aparecem nos corners e midpoints
- Para grupos: um contorno ao redor de todo o grupo, não de cada objeto individual

### Visual Feedback (Seleção em Caixa)
- Retângulo pontilhado ou com borda durante o drag
- Cor clara/óbvia para indicar "seleção em progresso"
- Cor diferente do contorno de seleção final

## Estados de Seleção

| Estado | Descrição |
|--------|-----------|
| **Não selecionado** | Objeto sem highlight ou handles |
| **Selecionado (único)** | Highlight + 8 handles visíveis |
| **Selecionado (múltiplo)** | Cada objeto tem seu highlight e handles |
| **Grupo selecionado** | Contorno ao redor de todo o grupo (não expõe objetos internos visualmente) |

## Prioridade de Clique

Se múltiplos objetos se sobrepõem no ponto de clique:
- **Objeto no topo da z-order (frente) é selecionado primeiro**
- Cliques subsequentes não cicla entre objetos (isso vem em feature futura)

## Interação com Outras Features

### Com Feature 1.3 (Movimentação)
- Arrastar um objeto selecionado move-o
- Arrastar múltiplos objetos selecionados move todos juntos

### Com Feature 1.4 (Redimensionamento)
- Handles aparecem apenas em seleção simples ou múltipla
- Drag em handle redimensiona

### Com Feature 2.2 (Cores)
- Mudar cores aplica apenas aos objetos selecionados

### Com Feature 3.2 (Trazer à Frente/Enviar Atrás)
- Aplica apenas aos objetos selecionados

## Estados Problemáticos (Edge Cases)

- **Clique em objeto já selecionado:** Mantém seleção (não deseleciona)
- **Shift+clique em objeto já selecionado:** Remove da seleção (toggle)
- **Drag-box começando em um objeto:** Deve ser ignorado (não inicia seleção em caixa)
  - Para fazer drag-box, deve começar em área vazia
- **Drag-box muito pequeno (apenas clique):** Não seleciona nada (caixa negligenciável)
- **Grupos selecionados:** Não expõe objetos internos para seleção individual
  - Desagrupar primeiro ou clicar em objeto dentro do grupo desseleciona o grupo

## Hierarquia de Clique (Clickability)

Se um objeto está dentro de um grupo:
- **Clique no objeto individualmente:** Seleciona o objeto, não o grupo
- **Clique na borda do grupo:** Seleciona o grupo como unidade

## Deseleção

### Como Desselecionar
1. Clique em area vazia do canvas
2. Pressione Escape
3. Clique em outro objeto (que substitui a seleção)

### Auto-deselecção
- Quando um objeto é deletado, deseleciona automaticamente
- Quando um objeto é movido para fora de sight (pan), continua selecionado se o usuário não clicou em outro lugar

## Visual Feedback - Cores Recomendadas

- **Contorno de seleção:** Azul (#0099FF) ou verde (#00CC66) com 2-3px de espessura
- **Handles:** Pequenos quadrados (6x6 ou 8x8px), mesma cor do contorno
- **Drag-box:** Retângulo pontilhado em azul claro, preenchimento transparente leve

## Não está incluído nesta feature

- Seleção por tipo (select all same type) → Feature futura
- Inversão de seleção (select all except current) → Feature futura
- Clique-ciclo entre objetos sobrepostos → Feature futura
