# Feature 2.2: Cores Customizáveis (Custom Colors)

## Objetivo
Permitir que o usuário customize cores de stroke (contorno) e fill (preenchimento) dos objetos.

## Seleção de Cor

### Interface
- Painel lateral esquerdo, seção "Estilos" (Feature 11.2)
- Dois color pickers:
  - **Stroke color:** cor do contorno/linha
  - **Fill color:** cor do preenchimento

### Métodos de Seleção

#### 1. Paleta Pré-definida
- 12-16 cores comuns (preto, branco, cinza, cores primárias, etc.)
- Clique rápido seleciona a cor

#### 2. Color Picker Visual
- Seletor de cor tipo "hue + saturation + brightness" ou similar
- Permite qualquer cor RGB

#### 3. Hex Input
- Campo de texto para entrada manual (ex: #FF5733)
- Valida entrada hexadecimal

## Aplicação de Cor

### Para Objetos Selecionados
- Mudar stroke/fill color aplica apenas aos objetos selecionados
- Se nenhum objeto selecionado, mudança afeta apenas o "default" para próximas formas criadas

### Para Novas Formas
- Se você criar uma forma, ela usa a cor padrão (Feature 1.1)
- Se você mudar a cor (via color picker) sem selecionar objeto, o "default" é atualizado
- Próximas formas criadas usam esse novo default

## Comportamento Especial por Forma

### Formas com Preenchimento
- Stroke e fill ambos aplicáveis
- Exemplo: retângulo, círculo, triângulo

### Linhas e Setas
- Apenas stroke é aplicável
- Fill é ignorado (ou pode ter "no fill" como opção)
- Cores de gradiente/padrão não são suportadas

### Texto
- Stroke é a cor do texto (ou ignorado, apenas fill)
- Fill é a cor de fundo da caixa de texto (ou "transparent")

## Persistência

### Salvar/Carregar
- Cores são armazenadas em cada objeto no .archidraw
- Ao reabrir, cada objeto retém suas cores

### Export
- **SVG:** cores são preservadas como atributos SVG
- **PNG:** cores são rasterizadas
- **Sketchline mode:** cores são respeitadas (não alteram o hand-drawn effect)

## Não está incluído nesta feature

- Gradientes ou padrões (Could Have)
- Transparência/opacidade (Could Have)
- Eyedropper tool para copiar cores (Could Have)
- Color palettes customizadas (Could Have)
- Per-object gradients (Feature futura)

## Estados de Cor

| Tipo | Cor Padrão |
|------|-----------|
| **Stroke** | #000000 (preto) |
| **Fill** | #FFFFFF (branco) |

## UX Recomendada

1. Clique em objeto para selecionar
2. Abra painel de estilos (já visível)
3. Clique em color picker de stroke ou fill
4. Escolha cor (paleta ou hex input)
5. Cor aplicada imediatamente
6. Outros objetos não afetados

## Atalhos Futuros (Could Have)

- Shift+clique em objeto para invocar color picker rápido
- Keyboard shortcuts para cores frequentes
