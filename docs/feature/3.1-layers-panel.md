# Feature 3.1: Painel de Camadas (Layers Panel)

## Objetivo
Visualizar a hierarquia visual (z-order) de todos os objetos no canvas em um painel lateral.

## Localização e Interface

### Painel Lateral
- Painel recolhível (lado direito ou esquerdo)
- Pode ser trocado com painel de estilos/propriedades (Feature 11.2)
- Mostra lista de todos os objetos em ordem de z-index

### Conteúdo da Lista
- **Última criada (topo)** aparece no topo da lista
- **Primeira criada (fundo)** aparece na base da lista
- Nomes automáticos: "Rectangle 1", "Circle 2", "Text 3", etc.
- Grupos aparecem como containers (podem ser expandidos)

## Interação com a Lista

### Seleção
- Clique em item seleciona o objeto no canvas
- Objeto é highlighted no canvas
- Múltiplo: Shift+clique para multi-seleção

### Reordenação via Drag-Drop
- Clique e arraste um item na lista
- Solta para reordenar z-index
- Ordem na lista reflete ordem de renderização (último = frente)

### Expansão de Grupos
- Grupos mostram ícone de expansão (▶ ou similar)
- Clique para expandir/colapsar
- Mostra objetos dentro do grupo indentados

## Visual Feedback

### Objeto Selecionado
- Item da lista tem background highlight (ex: azul claro)
- Objeto correspondente no canvas também é highlighted

### Hover
- Item tem background hover (mais claro que select)
- Tooltip mostra tipo e dimensões do objeto

### Drag-Drop em Progresso
- Linha indicadora mostra onde objeto será inserido
- Cursor muda para indicar reordenação

## Comportamento com Edições

### Renomear
- Duplo-clique em item para renomear
- Campo de texto edita nome customizado
- Enter ou clique fora salva nome

### Deletar
- Right-click em item mostra menu "Delete"
- Ou selecione item e pressione Delete
- Confirmação opcionalmente (Could Have)

## Não está incluído nesta feature

- Lock/Visibility toggles (Could Have)
- Search/filter (Could Have)
- Auto-naming inteligente (Could Have)
- Context menu completo (Feature 3.2 controla move up/down)

## Sincronização com Canvas

- Quando você move objeto no canvas, ordem na lista NÃO muda (apenas visual no canvas)
- Quando você reordena via Feature 3.2 (trazer à frente), lista é atualizada
- Quando você cria novo objeto, aparece no topo da lista

## Hierarquia com Grupos

Exemplo de estrutura:

```
Circle 1 (Group)
  ├── Rectangle 1
  └── Text 1
Line 1
Arrow 1 (Group)
  ├── Line 2
  └── Arrow head 1
Rectangle 2
```

Clique no grupo seleciona todo o grupo. Duplo-clique expande para mostrar internos.
