# Feature 2.1: Modo Hardline e Sketchline

## Objetivo
Oferecer dois estilos visuais distintos para um diagrama:
- **Hardline:** traços retos e ângulos agudos (formal, profissional)
- **Sketchline:** traços hand-drawn (informal, tipo Excalidraw)

## Escopo

### O que é Controlado
- **Apenas o estilo visual das linhas** das formas
- Toggle é **global por diagrama** (não por objeto individual)
- Afeta:
  - Contorno (stroke) de todas as formas
  - Linhas e setas

### O que NÃO é Controlado
- Preenchimento (fill) não muda
- Cor não muda
- Espessura não muda

## Funcionamento

### Hardline
- Traços são retos, com ângulos exatos
- Cantos são agudos e precisos
- Renderização usa linhas primitivas do canvas

### Sketchline
- Traços são levemente irregulares, como desenhados à mão
- Cantos têm pequenas variações
- Renderização usa algoritmo de hand-drawn simulation (ex: roughjs-like)
- Efeito é consistente e reproducível (não aleatório)

## Interface e Ativação

### Localização do Toggle
- Painel lateral esquerdo, seção "Estilos" (Feature 11.2)
- Toggle simples ou radio button: "Hardline" / "Sketchline"

### Aplicação
- Clique no toggle muda o estilo global imediatamente
- Todas as formas no diagrama atualizam visualmente
- Mudança não afeta dados (é apenas visual)

## Comportamento de Persistência

### Salvar/Carregar
- Modo selecionado é salvo no projeto (.archidraw)
- Ao reabrir projeto, retorna ao último modo selecionado

### Export
- **SVG e PNG:** respeitam o modo ativo (sketchline é renderizado como hand-drawn no SVG)
- **JSON (.archidraw):** armazena a preferência

## Não está incluído nesta feature

- Por-objeto style override (Feature futura)
- Customização de intensidade do hand-drawn effect
- Animação entre modos (muda imediatamente)

## Visual Comparison

| Aspecto | Hardline | Sketchline |
|--------|----------|-----------|
| **Ângulos** | Agudos, precisos | Levemente irregulares |
| **Linhas** | Retas perfeitas | Levemente curvas/tremidas |
| **Impressão** | Formal, CAD-like | Informal, rascunho |
