# Feature 8.1: Undo / Redo

## Objetivo
Permitir desfazer/refazer ações para edição segura.

## Operações

### Undo
- Hotkey: **Ctrl+Z**
- Menu: Edit → Undo
- Reverte a última ação

### Redo
- Hotkey: **Ctrl+Y** ou Ctrl+Shift+Z
- Menu: Edit → Redo
- Refaz a última ação desfeita

## O Que é Registrado como Ação

**Ações que criam undo points:**
- Criar forma
- Deletar forma
- Mover objeto(s)
- Redimensionar objeto
- Mudar cor (stroke/fill)
- Mudar modo (hardline/sketchline)
- Agrupar / Desagrupar
- Trazer à frente / Enviar atrás
- Alinhamento / Distribuição
- Renomear objeto (Feature 3.1)

**O que NÃO é registrado:**
- Seleção (clique em objeto)
- Hover
- Visualização (pan, zoom)
- Auto-save (persistência)

## Comportamento

### Stack Size
- Até 50 ações no stack
- Quando atinge 50, ação mais antiga é descartada

### After New Action
- Se você faz undo e depois uma nova ação, todo o redo history é descartado
- Exemplo: Cria A, cria B, undo → volta para A, cria C → B é removido do stack

### Batch Operations
- Operações que afetam múltiplos objetos são **uma** ação
- Exemplo: move 3 objetos = 1 undo point
- Alinhamento de 5 objetos = 1 undo point

## Visual Feedback

### Botões Undo/Redo
- Appear na toolbar (Could Have)
- Disabled quando stack está vazio
- Tooltip mostra ação sendo desfeita/refeita (Could Have)

### No Status
- Indicador de quantas ações no stack (Could Have)

## Persistence

- Undo stack é **LOCAL** à sessão (não persiste ao fechar browser)
- Ao fechar e reabrir projeto, undo stack é reset
- Auto-save (Feature 10.1) salva estado final, não permite "undo" após reabrir

## Não está incluído nesta feature

- Undo history visual (Could Have)
- Undo to specific point (Feature futura)
- Branch undo (Feature futura)
