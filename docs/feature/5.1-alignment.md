# Feature 5.1: Alinhamento de Objetos (Object Alignment)

## Objetivo
Alinhar múltiplos objetos rapidamente com 6 operações de alinhamento.

## Operações de Alinhamento

### Alinhamento Horizontal
1. **Align Left** - alinha tudo à borda esquerda do objeto mais à esquerda
2. **Align Center** - alinha tudo ao centro horizontal (média)
3. **Align Right** - alinha tudo à borda direita do objeto mais à direita

### Alinhamento Vertical
4. **Align Top** - alinha tudo ao topo do objeto mais alto
5. **Align Middle** - alinha tudo ao centro vertical (média)
6. **Align Bottom** - alinha tudo à base do objeto mais baixo

## Como Usar

### Pré-requisito
- Mínimo 2 objetos selecionados (Feature 1.2)
- Se apenas 1 selecionado, botões ficam disabled

### Interface
- Painel lateral esquerdo, seção "Alinhamento" (Feature 11.2)
- 6 botões com ícones visuais
- Hotkeys opcionalmente (ex: Ctrl+L para left, Ctrl+R para right, etc.)

### Aplicação
- Clique em um dos 6 botões
- Todos os objetos selecionados são alinhados instantaneamente
- Seleção permanece intacta

## Referência de Alinhamento

### Casos de 2 Objetos
- **Align Left:** ambos ficam alinhados à borda esquerda do mais à esquerda
- **Align Center:** ambos ficam no mesmo centro X
- **Align Right:** ambos ficam alinhados à borda direita do mais à direita

### Casos de 3+ Objetos
- Mesmo princípio aplicado a todos

## Visual Feedback

- Sem animação (mudança é instantânea)
- Objetos permanecem selecionados
- Painel de propriedades (Feature 11.2) mostra novas posições

## Grupos

- Grupos são tratados como unidades (não expõem objetos internos)
- Alinhamento respeita os bounds do grupo completo

## Não está incluído nesta feature

- Distribuição uniforme (Feature 5.2 controla isso)
- Snap to grid (Could Have)
- Smart guides (Could Have)
- Per-axis constraints (Could Have)

## Edge Cases

- **Objetos de tamanhos muito diferentes:** alinhamento funciona normal
- **Objetos sobrepostos:** alinhamento pode causar sobreposição (Z-order não muda)
- **Linhas/setas:** alinhamento se aplica aos endpoints
