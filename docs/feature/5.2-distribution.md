# Feature 5.2: Distribuição Uniforme (Uniform Distribution)

## Objetivo
Espaçar objetos com distância equidistante (uniformemente distribuído).

## Operações de Distribuição

### Distribuição Horizontal
- **Distribute Horizontally** - distribui espaçamento uniforme na horizontal
- Objetos mantêm ordem esquerda-direita, mas espaçamento fica igual

### Distribuição Vertical
- **Distribute Vertically** - distribui espaçamento uniforme na vertical
- Objetos mantêm ordem top-bottom, mas espaçamento fica igual

## Pré-requisitos

- **Mínimo 3 objetos selecionados** (Feature 1.2)
- Se menos de 3, botões ficam disabled

## Como Calcular Distribuição

### Horizontal
1. Identifica objeto mais à esquerda e mais à direita
2. Calcula espaço total disponível entre eles
3. Divide entre os gaps (N-1 gaps para N objetos)
4. Move objetos intermediários para espaçamento igual

**Exemplo:** 3 objetos em posições X: 0, 50, 200
- Espaço total: 200 - 0 = 200
- 2 gaps, espaçamento por gap: 200 / 2 = 100
- Resultado: 0, 100, 200

### Vertical
- Mesmo princípio mas na vertical (Y)

## Interface

- Painel lateral esquerdo, seção "Alinhamento" (Feature 11.2)
- 2 botões: "Distribute Horizontally" e "Distribute Vertically"
- Hotkeys opcionalmente

## Visual Feedback

- Mudança instantânea
- Objetos permanecem selecionados
- Espaçamento é visualmente óbvio

## Ordem dos Objetos

### Preservação de Ordem
- Distribuição respeita a **posição atual** dos objetos
- Não reorganiza ordem de criação
- Apenas ajusta spacing

### Exemplo com Ordem Aleatória
Se 3 objetos estão em X: 150, 50, 100 e você faz "distribute horizontally":
- Ordem natural (esquerda-direita): 50, 100, 150
- Distribuição vai ajustar espaçamento entre: 50, 100, 150
- Resultado: 50, 100, 150 (sem mudança se já espaçado uniformemente)

## Grupos

- Grupos são tratados como unidades individuais
- Distribuição respeita bounds do grupo

## Não está incluído nesta feature

- Custom spacing amount (Could Have)
- Distribuição por distância específica (Could Have)
- Align then distribute (Feature futura)

## Edge Cases

- **Objetos muito próximos:** distribuição ainda funciona, pode criar sobreposição
- **Linha:** endpoints são usados para cálculo
- **Grupos:** bounds do grupo inteiro é usado
