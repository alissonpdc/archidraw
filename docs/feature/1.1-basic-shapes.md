# Feature 1.1: Formas Básicas (Basic Shapes)

## Objetivo
Permitir que o usuário crie formas (retângulo, círculo, losango, triângulo, linha, seta, texto) no canvas via:
1. Botões de toolbar
2. Atalhos de teclado

Cada forma criada aparece no canvas com posição e tamanho definidos pelo drag do usuário (clique e arraste para desenhar).

## Formas Suportadas

- **Retângulo** (R)
- **Círculo** (C)
- **Losango** (D)
- **Triângulo** (T)
- **Linha** (L)
- **Seta** (A)
- **Texto** (X)

## Fluxo de Uso

### Etapa 1: Seleção da Ferramenta

**Opção A - Via Toolbar:**
- Clique no botão da forma desejada na barra superior
- O botão fica visualmente destacado (estado "ativo")
- Cursor muda para indicar qual ferramenta está selecionada

**Opção B - Via Teclado:**
- Pressione a tecla de atalho (R, C, D, T, L, A, X)
- Mesma mudança visual de cursor e estado de botão

### Etapa 2: Desenho no Canvas

- Usuário clica e arrasta no canvas para desenhar a forma
- Durante o arraste:
  - A forma aparece em tempo real no canvas conforme o usuário arrasta
  - Visual feedback mostra as dimensões (largura x altura)
  - Para linhas/setas: mostra o ponto inicial e final
  
### Etapa 3: Finalização

- Ao soltar o mouse (fim do drag), a forma é criada e permanece no canvas
- A forma está **selecionada** por padrão (após criação)
- A ferramenta permanece ativa para permitir desenhar múltiplas formas do mesmo tipo

**Comportamento especial:** Se o usuário apenas clicar sem arrastar (distância negligenciável):
- Nenhuma forma é criada
- O clique é ignorado

## Propriedades Iniciais da Forma

### Tamanho
- Determinado pelo drag do usuário (clique inicial até soltar)

### Posição
- O ponto inicial do drag (clique) define o canto superior-esquerdo (ou ponto de início para linhas/setas)

### Cor Padrão
Todas as formas criadas com:
- **Stroke (contorno):** preto (#000000)
- **Fill (preenchimento):** branco (#FFFFFF)
- **Stroke width:** 2px

**Nota:** Para linhas e setas, fill não é aplicável

### Z-order (Profundidade)
- Forma recém-criada sempre vai para o topo (última criada = na frente)
- Ordem de criação determina z-order natural

## Comportamento da Forma de Texto

Para a forma "texto" especificamente:

- Ao criar, aparece um campo de texto **em modo edição automático**
- O usuário pode começar a digitar imediatamente (sem duplo-clique necessário)
- Conforme digita, o texto aparece dentro da forma
- O campo de texto permanece ativo até:
  - O usuário clicar fora da forma (em outro lugar do canvas)
  - O usuário pressionar Escape
  - O usuário clicar em outra ferramenta

## Feedback Visual

### Cursor
- **Default:** seta normal
- **Com ferramenta de forma ativa:** ícone da forma (ex: quadrado para retângulo, círculo para círculo)
- Mudança é imediata ao selecionar/desselecionar ferramenta

### Botão da Toolbar
- **Inativo:** cor padrão do botão
- **Ativo:** highlight/background diferenciado (ex: background azul, texto branco)

### Canvas
- **Fundo:** branco puro (#FFFFFF), sem grid
- **Durante drag:** forma aparece com contorno preto e preenchimento branco
- **Depois de criada:** forma permanece visível com suas cores

## Não está incluído nesta feature

- Edição de propriedades (cores, texto) → Feature 2.2
- Seleção de múltiplas formas → Feature 1.2
- Movimentação ou redimensionamento → Features 1.3 e 1.4
- Alinhamento ou distribuição → Feature 5.1 e 5.2
- Magnetic snapping para setas → Feature 4.1

## Exemplos de Cenários

### Cenário 1: Desenhar um retângulo
1. Clique botão "Retângulo" ou pressione R
2. Cursor muda para indicar "modo retângulo"
3. Botão fica destacado
4. Clique e arraste no canvas para desenhar o retângulo
5. Solte o mouse para finalizar
6. Retângulo permanece visível, pronto para edição

### Cenário 2: Desenhar múltiplas setas
1. Pressione A para ativar ferramenta "Seta"
2. Desenhe a primeira seta (clique e arraste)
3. Ferramenta permanece ativa
4. Desenhe a segunda seta (clique e arraste novamente)
5. Setas aparecem em ordem de criação (primeira atrás, segunda na frente)

### Cenário 3: Criar uma forma de texto
1. Clique botão "Texto" ou pressione X
2. Clique no canvas para desenhar o espaço do texto
3. Campo de texto fica ativo automaticamente
4. Digite o conteúdo
5. Clique fora para finalizar edição

## Estados Problemáticos (Edge Cases)

- **Forma muito pequena (apenas clique):** Ignorar, não criar forma
- **Drag para fora do viewport:** Permitir desenhar "infinitamente" (canvas é ilimitado)
- **Arrastar no negativo:** Suportar (canvas tem espaço em todas as direções)
