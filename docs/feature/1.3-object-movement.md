# Feature 1.3: Movimentação de Objetos (Object Movement)

## Objetivo
Permitir que o usuário mova objetos selecionados para novas posições no canvas via drag-and-drop.

## Fluxo de Movimentação

### Movimentação Simples
1. Selecione um objeto (clique)
2. Clique e arraste o objeto para nova posição
3. Solte para finalizar

### Movimentação Múltipla
1. Selecione múltiplos objetos (Shift+clique ou drag-box)
2. Clique e arraste em qualquer um dos objetos selecionados
3. **Todos os objetos selecionados se movem juntos, mantendo suas posições relativas**
4. Solte para finalizar

## Comportamento de Movimento

### Durante o Drag
- O objeto(s) segue o cursor em tempo real
- Posição é atualizada continuamente (smooth movement)
- Objetos não "gruda" em lugar algum durante o movimento (sem snap-to-grid por padrão)
- Outros objetos não selecionados permanecem imóveis
- Z-order não muda durante o movimento

### Restrições
- **Sem restrição de limite:** O usuário pode arrastar objetos para fora do viewport
- **Canvas infinito:** Objetos podem ser posicionados em qualquer coordenada (positiva ou negativa)
- **Sem colisão:** Objetos podem sobrepor-se livremente

## Detecção de Movimento

### O que Pode ser Movido
- Objetos individuais selecionados
- Múltiplos objetos selecionados simultaneamente
- Grupos (como unidade)

### Ponto de Arraste
- Clique **dentro** do objeto para iniciar o movimento
- O ponto onde você clica define o "grip point" (o movimento é relativo a esse ponto)
- Para formas regulares: qualquer ponto dentro é válido

## Diferença Entre Movimento e Redimensionamento

- **Movimento:** Clique e arraste **dentro** do objeto (no corpo/preenchimento)
- **Redimensionamento:** Clique e arraste **nos handles** (corners/midpoints)

Se o usuário clicar em um handle e arrastar, inicia redimensionamento, não movimento.

## Visual Feedback

### Durante o Drag
- Objeto mantém seu visual (não muda cor ou transparência)
- Cursor permanece normal ou muda para "move" cursor (↔ ou similar)
- Posição é atualizada em tempo real

### After Release
- Objeto permanece na nova posição
- Se ainda está selecionado, handles permanecem visíveis
- Nenhuma animação ou transição (movimento é imediato)

## Interação com Seleção

- Movimento **não muda a seleção**
- Ao terminar o drag, os mesmos objetos permanecem selecionados
- Se você arrastar um objeto não selecionado:
  - O objeto **não se move** (precisa estar selecionado)
  - O clique é tratado como tentativa de seleção

## Casos Especiais

### Movimento de Grupo
- Ao mover um grupo, todos os objetos dentro se movem juntos
- Posições relativas entre objetos dentro do grupo são mantidas
- Ver Feature 6.1 para detalhes de grupos

### Movimento de Setas/Linhas
- Endpoints (pontos de início e fim) se movem com a linha
- Se a seta tem magnetic snapping (Feature 4.1), a conexão é mantida durante o movimento

## Não está incluído nesta feature

- Snap-to-grid (Could Have - Feature futura)
- Smart guides / alinhamento magnético (Could Have)
- Keyboard arrow keys para movimento (Could Have)
- Movement constraints / guidelines visuais (Could Have)

## Edge Cases

- **Arrastar muito rápido:** Movimento acompanha, sem lag (responsivo)
- **Arrastar fora da viewport:** Objeto sai de view mas permanece no canvas (pan para trazer de volta)
- **Arrastar enquanto faz zoom:** Movimento é relativo ao zoom atual (posição no mundo do canvas)
- **Arrastar em sobreposição:** Ordem de z-index não muda (Feature 3.2 controla isso)

## Estados de Feedback

| Estado | Visual |
|--------|--------|
| **Hover (pronto para mover)** | Cursor normal ou "move" cursor |
| **Durante drag** | Cursor "move", objeto segue cursor |
| **Após release** | Objeto na nova posição, sem feedback especial |
