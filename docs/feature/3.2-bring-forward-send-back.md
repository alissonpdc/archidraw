# Feature 3.2: Trazer à Frente / Enviar Atrás (Bring Forward / Send Back)

## Objetivo
Permitir que o usuário controle a sobreposição visual (z-order) de objetos via botões/hotkeys.

## Operações de Z-Order

### Trazer para Frente (Bring to Front)
- Hotkey: Ctrl+Shift+↑ ou similar
- Botão no painel de propriedades (Feature 11.2)
- Move objeto selecionado para o **topo da hierarquia** (será renderizado por último = na frente)

### Enviar para Trás (Send to Back)
- Hotkey: Ctrl+Shift+↓ ou similar
- Botão no painel de propriedades
- Move objeto selecionado para o **fundo da hierarquia** (será renderizado primeiro = atrás)

### Trazer Um Passo (Bring Forward)
- Hotkey: Ctrl+↑ ou Alt+↑
- Move um passo acima na z-order (troca com vizinho acima)

### Enviar Um Passo (Send Backward)
- Hotkey: Ctrl+↓ ou Alt+↓
- Move um passo abaixo na z-order (troca com vizinho abaixo)

## Comportamento

### Múltiplos Objetos Selecionados
- Se 2+ objetos estão selecionados:
  - "Trazer para Frente" move grupo como unidade para o topo
  - Ordem relativa entre eles é mantida
  - Similar para "Enviar para Trás"

### Efeito Visual
- Mudança é imediata (sem animação)
- Painel de camadas (Feature 3.1) é atualizado em tempo real
- Objeto permanece selecionado após operação

### Grupos
- Grupo é movido como unidade (não cada objeto dentro)
- Objetos dentro mantêm ordem relativa

## Casos Especiais

### Objeto já no Topo
- "Trazer para Frente" não faz nada (já está lá)
- "Trazer Um Passo" não faz nada

### Objeto já no Fundo
- "Enviar para Trás" não faz nada
- "Enviar Um Passo" não faz nada

### Quando Nada Selecionado
- Botões/hotkeys não funcionam (disabled ou sem efeito)

## Undo/Redo
- Cada operação de z-order é uma ação no undo stack (Feature 8.1)
- Ctrl+Z reverte o z-order change

## Não está incluído nesta feature

- "Arrange" menu com mais opções (Could Have)
- Drag-drop no painel de camadas (Feature 3.1 controla isso)
- Batch z-order changes
