# Feature 6.1: Agrupamento (Grouping)

## Objetivo
Combinar múltiplos objetos em uma unidade lógica para edição coletiva.

## Operações

### Agrupar (Group)
- Hotkey: **Ctrl+G**
- Menu: Right-click → Group
- Pré-requisito: 2+ objetos selecionados
- Cria um grupo contendo todos os objetos selecionados

### Desagrupar (Ungroup)
- Hotkey: **Ctrl+Shift+G**
- Menu: Right-click → Ungroup
- Pré-requisito: 1+ grupos selecionados
- Quebra o grupo, liberando objetos individuais

## Comportamento de Grupo

### Grupo como Unidade
- Quando um grupo é selecionado:
  - Um contorno aparece ao redor de todo o grupo
  - Handles de redimensionamento aparecem ao redor do grupo (não de cada objeto)
  - Arrastar o grupo move todos os objetos dentro junto

### Movimento
- Arrastar grupo = move todos os objetos dentro mantendo posições relativas
- Z-order relativa entre objetos internos é mantida

### Redimensionamento
- Redimensionar grupo redimensiona todos os objetos dentro proporcionalmente
- Shift+drag mantém proporção do grupo

### Seleção
- Clique no grupo seleciona todo o grupo
- Clique em objeto dentro do grupo desseleciona grupo e seleciona apenas esse objeto

## Grupos Aninhados (Hierarquia)

### Agrupar um Grupo
- Você pode selecionar 1+ grupos + objetos individuais
- Fazer Ctrl+G agrupa tudo em um super-grupo
- Resultado: hierarquia de grupos

### Desagrupar um Grupo Aninhado
- Ctrl+Shift+G desagupa apenas o nível imediato
- Grupos internos permanecem intactos

### Profundidade Máxima
- Sem limite teórico, mas praticidade recomenda não muito profundo
- Painel de camadas (Feature 3.1) mostra hierarquia

## Painel de Camadas com Grupos

### Visualização
- Grupos aparecem como containers expandíveis
- Clique em ▶ para expandir/colapsar
- Objetos internos aparecem indentados

### Reordenação
- Drag-drop de grupo na lista reordena grupo como unidade
- Drag-drop de objeto dentro de grupo (via painel) move objeto entre grupos (Could Have - talvez não suportado)

## Comportamento de Deletar

### Deletar Grupo
- Deleta o grupo E todos os objetos dentro
- Confirmação opcionalmente (Could Have)

### Deletar Objeto Dentro de Grupo
- Se você expande grupo no painel de camadas e deleta um objeto
- Apenas aquele objeto é deletado
- Grupo permanece com os outros objetos

## Undo/Redo

- Ctrl+G e Ctrl+Shift+G são operações que entram no undo stack (Feature 8.1)
- Ctrl+Z reverte agrupamento/desagrupamento

## Não está incluído nesta feature

- Grupo transformado em símbolo (Symbol/Component - Could Have)
- Bloqueio de grupo (Lock - Feature 11.4 Could Have)
- Visibilidade toggle de grupo (Feature 11.4 Could Have)
- Propriedades coletivas do grupo (Could Have)

## Edge Cases

- **Desagrupar vazio:** n/a (grupo sempre tem conteúdo)
- **Grupo dentro de grupo:** suportado, hierarquia funciona
- **Movimento de objeto para outro grupo:** drag-drop no painel (Could Have)
